# Domain Glossary & Ubiquitous Language

A shared dictionary of domain concepts and technical terms to ensure consistent communication across developers, stakeholders, and AI assistants.

---

## Terms & Definitions

### ADR (Architecture Decision Record)
A lightweight document capturing an architectural decision, its context, consequences, and trade-offs. Stored under `docs/memory/decisions/`.

### Context Bank
A structured set of markdown files under `docs/memory/context/` designed to be read by AI coding agents and developers to understand project state and conventions.

### Handoff Log
A structured, timestamped record authored before switching machines or ending a shift, detailing completed work, in-flight changes, blockers, and next steps.

### RFC (Request for Comments)
A technical design proposal outlining a major proposed change before code implementation begins.

### App Net
The internal Docker bridge network that connects the frontend and backend services for local container-to-container communication.
