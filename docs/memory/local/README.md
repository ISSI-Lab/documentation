# Developer-Private Local Memory

Files created in this directory (with exception of `.gitkeep` and this `README.md`) are **strictly ignored by Git**.

## Intended Use
- Personal scratchpads and notes during active feature exploration.
- Machine-local benchmarks, profiling logs, or test dumps.
- Draft ideas before turning them into official RFCs or PRDs.

> **Warning**: Never put uncommitted production code here. Everything in this directory stays on your current machine.
