# Request for Comments (RFCs)

RFCs are design proposals for major features, cross-cutting concerns, or architectural refactors.

## Process
1. Run `python3 scripts/new_record.py rfc "proposal-name"` to create a new RFC.
2. Fill out the RFC template (`docs/templates/rfc-template.md`).
3. Open a pull request for team review and discussion.
4. Once consensus is reached, mark status as `Accepted` or `Rejected`.
5. Significant architectural decisions resulting from an RFC should be recorded in [`../../memory/decisions/`](../../memory/decisions/).
