# Architecture Blueprints

This directory documents the structural architecture of the system.

## Core Documents
- [`00-system-overview.md`](00-system-overview.md): Container topology, communication flow between frontend, backend, and external storage.

## Architecture Guidelines
- Architectural changes must be proposed via an RFC in [`../rfcs/`](../rfcs/) and finalized as an ADR in [`../../memory/decisions/`](../../memory/decisions/).
- Diagrams should follow the C4 model (Context, Container, Component, Code).
